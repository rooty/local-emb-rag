## Objawy
Klasyczny program Outlook zatrzymuje się na ekranie powitalnym z komunikatem „Trwa przetwarzanie” (Processing).

## Zastosowanie
Klasyczny Outlook (Classic Outlook) w systemie Windows; nie dotyczy nowej wersji Outlooka.

## Kroki
1. Zamknij program Outlook w standardowy sposób; jeśli masz ważne niezapisane dane, nie wymuszaj zamykania procesu.
2. W oknie Uruchom (Windows Run) wpisz outlook.exe /safe.
3. Jeśli program się otworzy, zamknij tryb awaryjny i uruchom Outlooka normalnie.

## Weryfikacja
Sprawdź uruchamianie programu Outlook w trybie standardowym.

## Eskalacja
Jeśli program się nie uruchamia lub błąd powraca, skontaktuj się ze specjalistą; nie usuwaj profilu ani plików bazy danych poczty.
