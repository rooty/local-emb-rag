## Objawy
PowerPoint nie otwiera się lub powtarzalnie zawiesza się podczas uruchamiania.

## Zastosowanie
Microsoft PowerPoint na komputery (desktop) w systemie Windows; nie dotyczy wersji macOS ani wersji webowej.

## Kroki
1. Zapisz otwarte prezentacje i zamknij PowerPoint w standardowy sposób.
2. W oknie Uruchom systemu Windows (Windows Run) wpisz powerpnt /safe.
3. Sprawdź uruchomienie; aby wrócić do trybu zwykłego, zamknij program i uruchom go ponownie normalnie.

## Weryfikacja
Porównaj uruchamianie w trybie awaryjnym i standardowym.

## Eskalacja
Jeśli problem nadal występuje, skontaktuj się ze specjalistą; nie usuwaj plików prezentacji ani ustawień aplikacji.
