# Резервное копирование PostgreSQL

Ежедневный бэкап делается через pg_dump в формате custom (-Fc), файлы складываются в S3-бакет backups-prod с жизненным циклом 30 дней.

Для восстановления используйте pg_restore с флагом --clean на пустой базе. Перед восстановлением в прод обязательно проверьте дамп на стейджинге.

Для point-in-time recovery дополнительно включено архивирование WAL через wal-g.
