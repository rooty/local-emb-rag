# Доступы для нового сотрудника

Новому инженеру нужно: учётка в GitLab, VPN-профиль WireGuard, доступ в Grafana (только чтение) и kubeconfig для стейджинга.

Заявку оформляет тимлид в Jira, проект ACCESS. Доступ к продакшен-кластеру выдаётся только после месяца работы и согласования с руководителем.

SSH-ключи добавляются через репозиторий infra/users, никаких ключей вручную на серверах.
