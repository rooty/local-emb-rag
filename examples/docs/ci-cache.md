# Медленные сборки в GitLab CI

Если пайплайн стал собираться долго, проверьте, работает ли кэш зависимостей: ключ кэша должен зависеть от lock-файла (go.sum, poetry.lock).

Для Docker-сборок включите BuildKit и --cache-from с образом из реестра. Порядок слоёв важен: сначала копируйте файлы зависимостей, потом исходники.

Раннеры с тегом heavy выделены под тяжёлые сборки, у них 16 ГБ памяти.
