# Где хранить секреты

Все пароли, токены и ключи хранятся в HashiCorp Vault, путь secret/<команда>/<сервис>. В репозитории секретов быть не должно, проверку делает gitleaks в CI.

В Kubernetes секреты попадают через External Secrets Operator, который синхронизирует их из Vault.

Ротация паролей баз данных — раз в 90 дней, её выполняет Vault database engine автоматически.
