# Рост задержек Redis

Если задержки Redis выросли, проверьте SLOWLOG GET и наличие больших ключей (redis-cli --bigkeys). Команды KEYS * в проде запрещены, используйте SCAN.

Также посмотрите, не совпадает ли рост с сохранением RDB-снапшота: fork на большом инстансе может подвешивать запросы.

Метрика redis_commands_duration_seconds выведена на дашборд Redis в Grafana.
