# На сервере закончилось место на диске

Сначала найдите, что занимает место: df -h, затем du -xh --max-depth=1 / | sort -h. Частые виновники: логи в /var/log, старые образы Docker, core-дампы.

Docker чистится командой docker system prune -af (удалит неиспользуемые образы). Для журналов systemd: journalctl --vacuum-size=500M.

Если df показывает свободное место, а запись всё равно не идёт, проверьте иноды: df -i.
