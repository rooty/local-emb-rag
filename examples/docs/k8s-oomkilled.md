# Под перезапускается с OOMKilled

Статус OOMKilled означает, что контейнер превысил лимит памяти (resources.limits.memory) и ядро убило процесс.

Проверить: kubectl describe pod, поле Last State. Посмотреть фактическое потребление: kubectl top pod или графики в Grafana.

Решение: поднять лимит, если потребление растёт легитимно, или искать утечку. Для JVM-сервисов задайте -XX:MaxRAMPercentage, иначе куча не учитывает лимит контейнера.
